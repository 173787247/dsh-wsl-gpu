# dsh-wsl-gpu

DeepSeek Harness tool: probe nvidia-smi / GPU visibility inside WSL.

## Install

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-gpu
```

Restart `dsh web`. Tool / feature: `gpu_doctor`.

Part of **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**.
